---
title: Glossary
description: Words the app and the contracts share.
---

| Word | Meaning |
| --- | --- |
| Cover | The policy. It pays USDG if the named drop is still there |
| Drop | How far price must fall from the entry. One of 50, 60, 70, 80, 90, 95 percent |
| Term | How long the policy stays on. 1, 3, 7, 14, or 30 days. Not a crash window |
| Entry | The 5-minute average at `activeFrom` |
| `activeFrom` | Purchase time plus 30 minutes. Settle is inactive before this |
| Expiry | Purchase time plus the term |
| Cell | The USDG pool for one drop on one token. Share-accounted |
| Premium | USDG the buyer pays. Streams to the cells that filled the policy |
| Payout | USDG reserved at settle, capped by coverage and by the loss from the entry |
| Settle | The call that proves the drop and reserves the payout |
| Release | The call that sends the reserved USDG to the buyer after the challenge window |
| Challenge | A backing LP's on-chain recheck during those 2 hours |
| Quote | The other side of the pool. USDG or WETH |
| Pool ref | `keccak256` of the v4 pool key: currencies, fee, tick spacing, hooks |
| Lock adapter | Contract that attests liquidity cannot be pulled |
| Depth | Locked quote a seller must consume to push the price down by a drop |
| Keeper | The bot that records prices |
| Factory | `MarketFactory`. One vault per token |
| Engine | Premium math. Live path is `BoundedRiskEngine` around `ParaapeRiskEngine` |
